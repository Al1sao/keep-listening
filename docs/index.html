Cómo probarlo

Para ejecutarla en una computadora propia (GitHub Pages solo publica esta documentación; la versión en línea está en Render). Los pasos completos están en el README; en resumen:

git clone https://github.com/Al1sao/keep-listening.git
cd keep-listening
docker compose up --build

y abrir http://localhost:8000. Cuentas de prueba: sophia / Usuario1234 y admin / Admin1234.
