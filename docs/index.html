Cómo probarlo

La aplicación es un proyecto Django y se ejecuta en la computadora (GitHub Pages solo publica esta documentación). Los pasos completos están en el README; en resumen:

git clone https://github.com/Al1sao/keep-listening.git
cd keep-listening
docker compose up --build

y abrir http://localhost:8000. Cuentas de prueba: sophia / Usuario1234 y admin / Admin1234.
